# Who am I?

A simple football trivia game, written as a web application using the `shiny` (https://shiny.posit.co). The game is summarised below:

- Guess the current or former professional footballer from the clues.

- Clues are revealed sequentially, with each incorrect guess (or skip).

- The fewer clues needed to arrive at the correct answer, the higher your score.

Play here: https://allyourbayes.com/posts/who_am_i/
